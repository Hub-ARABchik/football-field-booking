# Мигратсияҳои пойгоҳи додаҳо

Мигратсияҳо барои навсозии пойгоҳи мавҷудаанд; онҳоро танҳо баъд аз нусхаи эҳтиётӣ ва санҷиш дар clone иҷро кунед.

## 001 — васеъкунии FFBS-и кӯҳна

`001_expand_existing_ffbs.sql` барои пойгоҳи кӯҳнае навишта шудааст, ки аз `database/database.sql` сохта шудааст. Он:

- ролҳои `client/admin`-ро ба `CUSTOMER/ADMIN` мегузаронад;
- нақши `OWNER`-ро илова мекунад;
- ownership, маълумоти ҷойгиршавӣ ва moderation status-и майдончаҳоро илова мекунад;
- давомнокии брон ва майдонҳои аудитро илова мекунад;
- ҷадвалҳои тасвир, ҷадвали корӣ, шарҳ, огоҳӣ ва аудитро месозад;
- маълумоти мавҷударо нест намекунад.

Ин мигратсия **як маротиба** иҷро мешавад ва барои иҷрои такрорӣ пешбинӣ нашудааст. Агар сутун ё ҷадвалро пештар дастӣ илова карда бошед, аввал скриптро мутобиқ кунед.
