# Сравнительная матрица аналогов

## 1. Цель сравнения

Целью сравнения является анализ существующих способов и систем бронирования футбольных площадок, выявление их преимуществ и недостатков, а также определение функциональных особенностей разрабатываемой системы Football Field Booking System (FFBS).

## 2. Сравнение систем

| Критерий | Традиционный способ (телефон) | Универсальная система бронирования | FFBS |
|---|---|---|---|
| Регистрация пользователей | Нет | Есть | Есть |
| Поиск площадок | Вручную | Есть | Есть |
| Просмотр информации о площадках | По телефону | Есть | Есть |
| Просмотр расписания | По телефону | Зависит от системы | Есть |
| Бронирование онлайн | Нет | Есть | Есть |
| Управление площадками | Владельцем вручную | Зависит от системы | Есть |
| Управление бронированиями | Вручную | Есть | Есть |
| Отмена бронирования | По звонку | Зависит от системы | Предусмотрена |
| Централизованное управление | Нет | Есть | Есть |

## 3. Преимущества FFBS

- Специализация на бронировании футбольных площадок.
- Возможность самостоятельного добавления площадок владельцами.
- Удобный поиск доступных футбольных площадок.
- Просмотр свободного времени для бронирования.
- Централизованное управление расписанием.
- Автоматизация процесса оформления бронирований.

## 4. Вывод

Проведённое сравнение показывает, что традиционный способ бронирования с использованием телефонной связи имеет ряд ограничений, связанных с ручной обработкой запросов и отсутствием единой информационной системы.

Разрабатываемая система Football Field Booking System (FFBS) направлена на автоматизацию процесса поиска и бронирования футбольных площадок, упрощение взаимодействия между клиентами и владельцами площадок, а также повышение удобства управления расписанием.
