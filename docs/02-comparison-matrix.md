### 1.2. Описание шкалы оценивания

Для объективного сравнения используется единая трёхуровневая шкала:

- **0** — функциональность отсутствует или не подтверждена.
- **1** — функциональность присутствует частично либо имеет существенные ограничения.
- **2** — функциональность реализована и соответствует установленным требованиям.

Подробное описание оценивания:

**K1 — Каталог футбольных площадок и поиск**

- `0` — отсутствует каталог футбольных площадок.
- `1` — доступен ограниченный список площадок без полноценной системы поиска и фильтрации.
- `2` — имеется каталог площадок с возможностью поиска и фильтрации по местоположению, стоимости и характеристикам.

**K2 — Проверка доступности и онлайн-бронирование**

- `0` — бронирование через систему отсутствует.
- `1` — бронирование доступно, но подтверждение или проверка свободного времени выполняется вручную.
- `2` — пользователь может самостоятельно выбрать свободную дату и время и оформить онлайн-бронирование.

**K3 — Личный кабинет владельца площадки**

- `0` — отсутствуют инструменты управления площадками.
- `1` — имеются отдельные функции управления, но полноценный личный кабинет ограничен.
- `2` — владелец может самостоятельно добавлять площадки, изменять информацию, управлять расписанием и бронированиями.

**K4 — Управление расписанием и предотвращение двойного бронирования**

- `0` — отсутствует электронное расписание.
- `1` — расписание доступно, но управление занятостью и предотвращение конфликтов ограничены.
- `2` — система автоматически отображает занятость, контролирует временные интервалы и предотвращает конфликтующие бронирования.

**K5 — Онлайн-оплата и управление платежами**

- `0` — оплата через систему отсутствует.
- `1` — доступна ограниченная интеграция с платежными сервисами или отдельные способы регистрации платежей.
- `2` — реализована полноценная онлайн-оплата с обработкой платежного статуса и подтверждением операции.

**K6 — Уведомления и история бронирований**

- `0` — отсутствуют уведомления и история заказов.
- `1` — реализована только часть функций, например уведомления без полноценной истории бронирований.
- `2` — пользователь может просматривать историю бронирований и получать уведомления об изменении их состояния.

**K7 — Адаптация для мобильных устройств**

- `0` — система практически непригодна для использования на мобильных устройствах.
- `1` — имеется адаптивная веб-версия либо ограниченное мобильное приложение.
- `2` — доступна полноценная адаптивная веб-версия и официальные мобильные приложения.

**K8 — Локализация и местные способы оплаты**

- `0` — поддержка русского и таджикского языков и местных платежных решений отсутствует.
- `1` — поддерживается только часть требований: один из языков или отдельные подходящие платежные решения.
- `2` — полноценно поддерживаются русский и таджикский языки, а также платежные решения, доступные в Таджикистане.

**K9 — Самостоятельная регистрация владельцев**

- `0` — самостоятельная регистрация владельцев невозможна.
- `1` — регистрация возможна только через обращение к администрации или после индивидуального согласования.
- `2` — владелец может самостоятельно создать аккаунт и начать работу с системой.

**K10 — Аналитика и статистика деятельности**

- `0` — инструменты аналитики отсутствуют.
- `1` — доступна ограниченная статистика бронирований.
- `2` — имеется аналитическая панель с данными о количестве бронирований, доходах, загруженности и эффективности площадок.

**Примечание:** если информация о функциональности не подтверждена официальной документацией, ей не присваивается максимальная оценка. Оценки являются предварительной экспертной оценкой по доступным открытым материалам, а не результатом полноценного тестирования закрытых аккаунтов аналогов.

## 4. Итоговые расчёты и результаты

Для получения объективного сравнительного результата каждому критерию присваивается весовой коэффициент. Балл аналога умножается на вес соответствующего критерия, после чего полученные значения суммируются.

Если максимальная оценка по отдельному критерию не подтверждена или критерий неприменим, его вес исключается из знаменателя. В данной предварительной матрице все десять критериев оценены.

### 4.1. Формулы расчёта

Обозначения:

- `S` — итоговый взвешенный балл аналога.
- `Kᵢ` — оценка аналога по определённому критерию.
- `Wᵢ` — вес соответствующего критерия.
- `Smax` — максимальное количество баллов.

Формула итогового балла:

\[
S=\sum_{i=1}^{n}(K_i \times W_i)
\]

Максимальный балл:

\[
S_{max}=2\times\sum_{i=1}^{n}W_i
\]

Процент соответствия:

\[
P=\frac{S}{S_{max}}\times100\%
\]
