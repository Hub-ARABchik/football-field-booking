# 07 — Диаграмма развертывания FFBS

## Назначение

Диаграмма описывает предлагаемое физическое размещение компонентов Football Field Booking System (FFBS), взаимодействие пользовательского браузера с сервером приложения, базой данных, файловым хранилищем и внешними сервисами.

## Узлы развертывания

1. **Устройство пользователя** — веб-браузер и веб-интерфейс FFBS.
2. **Интернет** — передача запросов между клиентом и сервером.
3. **Сервер приложения** — веб-приложение, REST API, аутентификация и авторизация, обработка бронирований, проверка доступности и уведомления.
4. **Сервер базы данных** — реляционная БД FFBS с таблицами `users`, `fields`, `field_images`, `field_schedules`, `bookings`, `payments`, `reviews` и `notifications`.
5. **Сервер файлового хранилища** — фотографии футбольных площадок и другие загруженные файлы.
6. **Внешние сервисы** — платёжный провайдер и провайдер Email / SMS.

## Важные архитектурные правила

- Клиент взаимодействует с сервером по HTTPS.
- Аутентификация, авторизация и проверка прав владельца выполняются на серверной стороне.
- Владелец может управлять только собственными площадками.
- Проверка пересечения активных бронирований выполняется на сервере внутри транзакции.
- Активными статусами бронирования считаются `PENDING` и `CONFIRMED`.
- Статус платежа хранится и обрабатывается отдельно от статуса бронирования.
- Внешние платёжные и коммуникационные сервисы рассматриваются как отдельные зависимости.

## Примечание о реализации

Это предлагаемая логическая топология развертывания FFBS, основанная на согласованной модели системы. Конкретные технологии, адреса узлов, контейнеры, порты, ОС, облачный провайдер и схема сетевой сегментации должны быть уточнены по фактической конфигурации проекта и среды эксплуатации.
