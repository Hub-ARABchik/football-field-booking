# Анализ предметной области FFBS

Football Field Booking System (FFBS) — веб-система для поиска и бронирования футбольных площадок.

Система предоставляет следующие возможности:

- Регистрация и авторизация пользователей.
- Добавление футбольных площадок владельцами.
- Просмотр и поиск доступных площадок.
- Проверка свободного времени.
- Бронирование футбольных площадок.
- Управление расписанием и бронированиями.
